# GoEncode

GoEncode is a Windows-based C# application designed to manage and automate FFmpeg-based video encoding workflows.  
It focuses on batch processing, hardware acceleration, and reliable execution of encoding jobs for large media libraries.

## Primary Goals
- Orchestrate FFmpeg encoding jobs in a structured and repeatable way
- Support GPU and CPU-based encoding workflows
- Provide clear progress tracking and job visibility
- Remain maintainable and extensible as the project evolves

## Technology Stack
- C# (.NET, Windows)
- FFmpeg
- Windows Forms / WPF (depending on implementation)
- External process execution and job orchestration

## Project Status
This project is under active development.  
Core functionality is implemented, with ongoing refactoring and feature expansion.

## Notes
This repository is currently private and intended for personal development and experimentation.
