# CQ25 Gate 3 Research Closeout

**Status: Closed — Inconclusive.**

P1 was frozen but never executed. P2 was executed only through Slot 2, attempt 1. P2 is non-scoreable because its frozen source-family identities used container duration, while production execution uses the canonical program/video duration. The remaining-candidate audit found this mismatch was systemic rather than isolated.

The compatible CQ25 evidence consists of three successful measurements from independent source families. Only one chronological target had jointly supported Baseline and Temporal forecasts. On that single target, Baseline Ratio APE was 44.569%, Baseline Direct APE was 8.379%, Temporal Ratio APE was 44.569%, and Temporal Direct APE was 8.379%. This sample is insufficient to establish Temporal improvement or a general Direct-over-Ratio advantage.

No predictor was promoted, and no production prediction-policy change is authorized by this experiment. No additional Gate 3 encode cohort is planned. P1/P2 freezes and research journals are intentionally preserved as immutable historical artifacts.

If this research is reopened, it must use a new experiment and construct and freeze source-family identities through the same canonical production plan and `GetSourceFamilyKey` path used during execution.
